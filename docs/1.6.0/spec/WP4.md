## C. UI-side state bugs (robust-2, arch-3)
- Every activity start (download in `launch`, update in `update_engine`, and from WP5 collection in `launch_collection`) does `self.run_token += 1; token = self.run_token`, creates its emit closure, which returns immediately when `token != self.run_token`, and registers its thread: `self.worker = thread; self.worker_operation = self.operation`. A worker abandoned by the watchdog, by Stop-during-update or by a forced close can then never end a later job. Until WP5 the old `launch_collection` registers nothing; with `worker` None the watchdog ignores collections.
- Download emit closure: `try: self.library.download_event(job_id, kind, value)` for kinds `item, title, media, file, queued, item_done, done` (only when `job_id`); `except Exception`: `applog` traceback and, once per job, queue the log line `历史记录写入失败，下载本身不受影响。`; `finally: self.events.put((kind, value))`.
- `launch()` order (§E) guarantees that nothing after `set_busy(True)` can raise without `set_busy(False)`.
- `on_done`, `on_update_done` and (WP5) `collect_done` call `self.set_busy(False)` in a `finally`.
- `watchdog()` every second: if `busy` and `self.worker is not None` and `self.worker_operation == self.operation` and not `self.worker.is_alive()` and `self.events.empty()` on two consecutive ticks: log `后台任务意外结束，已恢复界面。`, `self.run_token += 1`, set `self.worker = None` and call `self.handle` with the terminal event of the operation: `('done', {'success': 0, 'failed': 0, 'files': [], 'cancelled': True, 'failed_urls': [], 'pending_urls': []})`, `('update_done', {'cancelled': True})` or `('collect_done', {'cancelled': True})`. Tests that set `busy` without a worker are unaffected. The watchdog must only ever judge the thread of the activity that is running now: `self.worker` is cleared whenever an activity ends (third `set_busy` line below, and in `force_close`), and the `worker_operation` comparison covers an activity that was started without registering. Without both, the dead thread of a finished download would make the watchdog end the next collection or engine update after two quiet seconds (page load, Chrome start, GitHub request) while its real worker is still running.
- `poll`: after the verbatim move, the only change is the tail - replace `self.render_wait()` and the `if self.closing ... else ...` block by: `try: self.flush_log(); self.render_wait()` / `except Exception: self.logger.exception('UI tick failed')` / `finally:` the original `if self.closing and not self.busy: self.finish_close() else: self.after(25, self.poll)`.
- `set_busy`: after the verbatim move, add exactly three things: (a) directly after `self.busy = busy`: `if not busy: self.worker = None`; (b) after the first loop: `for control in self.input_controls: control.configure(state='disabled' if busy and self.operation != 'download' else 'normal')`; (c) as last line `self.refresh_shell()`. `input_controls` = link box, 粘贴, 导入 TXT, 清空, start button (they leave `controls`).
- Close: `on_close` while busy asks `停止并关闭` / `当前任务尚未完成。要停止任务并关闭吗？`; on yes `closing = True`, `stop()`, `self.after(8000, self.force_close)`; a second click on X while `closing` calls `force_close()` at once. `force_close()`: cancel the runner on a thread, `self.run_token += 1`, `self.worker = None`, `finish_close()`. `finish_close()`: `save_settings()`, `applog` flush, `destroy()`.
- `stop()` when `operation == 'update'`: `self.runner.cancel()`, `self.run_token += 1`, `self.drain_events()`, then `if self.busy: self.handle('update_done', {'cancelled': True})` (the UI is released at once; robust-12). `drain_events()` (new shell method; `poll` is not touched): `while True: try: kind, value = self.events.get_nowait()` / `except queue.Empty: break`; `self.handle(kind, value)` inside `try/except Exception` (logged). After the token bump the old worker can queue nothing more, so once the queue is drained no stale `update_progress` can overwrite `已取消更新。` and no stale `update_done` can end a later job. As a second guard `on_update_status` / `on_update_progress` return at once unless `self.busy and self.operation == 'update'`.
