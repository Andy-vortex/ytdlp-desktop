## A. State bugs
- `handle_collection('collect_done')` (arch-3 a, R4): run the existing bookkeeping (`library.job`, `load_collection_record`, `finish_subscription`) inside `try/except Exception` (traceback to `applog.get('ui')`, visible line `采集记录保存失败：<error>`); in the `finally`: `self.collection_job = None`, `self.active_subscription = None`, `self.collection_background = False`, `self.set_busy(False)`, `self.collect_stop.configure(state='disabled')`. Only then update the status texts.
- `launch_collection(options, job_id=None, title=None, background=False)` follows the activity-start rule of WP4 §C (the watchdog and the stale-worker guard depend on it): `self.run_token += 1; token = self.run_token`; the runner's emit becomes `lambda kind, value: token == self.run_token and self.events.put((kind, value))`; the thread is created as a variable, registered with `self.worker = thread; self.worker_operation = 'collect'`, then started. (robust-13:) store `self.collection_background = background`. When `background`: do not clear `collected_links`/`collected_pages`, do not call `render_collection_links()`, do not change `collect_text`, `collect_status` or the start-URL box. In `handle_collection`: `collect_page` and `collect_status` events of a background run are not shown on the collect page (pages are persisted by the worker; `append_log` still records them); `collect_error` only logs; at `collect_done` skip `load_collection_record(record)` but still call `finish_subscription` and `refresh_library()`. While a background check runs, set `self.link_hint` (download page) to `正在检查订阅“<name>”，完成后可以开始下载` and restore the default hint afterwards.
- `check_subscription(row=None, automatic=False)` passes `background=automatic`; a manual check behaves as today (shows the collect page and the results).
- `subscription_tick`: body inside `try/except Exception` (log), re-arm in `finally: if not self.closing: self.after(15000, self.subscription_tick)`. The busy/smoke conditions and the single `check_subscription(row, automatic=True)` call stay exactly as they are (`test_library_ui.py:62-71`).
- `init_library(prefs)` (robust-6): `path = Path(self.output.get()) / 'test-library.sqlite3' if self.smoke_mode else None`; `self.library, self.library_warning = library.open_library(path)`; the warning, when not empty, is logged and shown as a WARN caption above the tabs of the library page. `archive_enabled`/`archive_root` defaults come from `prefs` as today.
